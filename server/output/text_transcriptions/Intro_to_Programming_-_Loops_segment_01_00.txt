 a stopping condition is met. There are different types of loops and each programming language has their own syntax, but all loops have one thing in common, a stopping condition. This condition is checked every round, and the loop will continue to run until the condition is reached. If our goal was to frost four cupcakes, the loop stopping condition would specify to continue to frost cupcakes until four cupcakes have been frosted. So our loop would run frost cupcakes four times, giving us four fully frosted cupcakes. Loops allow us to tell the computer where to start and provide a condition upon which to stop, all in a few easy-to-read lines of code, which is super sweet.
